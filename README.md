# Sentinel — منصة الذكاء الاصطناعي الموحدة 🛡️🤖

**Sentinel** هي منصة ذكاء اصطناعي **شاملة وعملية** (ليست محاكاة) تجمع في مكان واحد:

- 🧠 **محرك استدلال LLM متعدد الخلفيات** — يعمل مع OpenAI/أي واجهة متوافقة، أو موديل محلي (Transformers / GGUF)، أو خلفية `echo` تعمل بلا أي اعتمادات.
- 🤖 **وكيل ReAct حقيقي** — حلقة تفكير/تنفيذ/ملاحظة فعلية تستخدم الأدوات خطوة بخطوة (بدل الكود الوهمي السابق).
- 🧰 **طبقة أدوات حقيقية ومعزولة (sandbox)** — تنفيذ كود، ملفات، أوامر shell بقائمة سماح، تحليل بيانات، جلب ويب.
- 🛡️ **محرك أمن سيبراني دفاعي** — كشف تسريب المفاتيح، تحليل ثابت (SAST)، مراجعة الاعتمادات، وتدقيق الإعدادات.
- 🌐 **REST API + لوحة تحكم ويب** — بلا أي اعتمادات خارجية (Python stdlib فقط).

> **الفلسفة الأخلاقية:** Sentinel أداة **دفاعية ومُصرّح بها**. تساعدك على تأمين وتحسين أنظمتك أنت والأهداف المصرّح لك بالعمل عليها. ولا تُستخدم في اختراق غير مصرّح به أو إيذاء أنظمة الآخرين.

## ⚡ تشغيل سريع (بدون تثبيت أي شيء)

النواة تعمل بمكتبات Python القياسية فقط:

```bash
# لوحة التحكم + الـ API
python main.py serve --port 8080

# تشغيل الوكيل على هدف
python main.py agent "احسب 23*19 ثم احفظ الناتج في result.txt"

# محادثة سريعة
python main.py chat "اشرح لي مبدأ الـ zero-trust"

# فحص أمني دفاعي لمجلد/ملف
python main.py scan .

# حالة المنصة
python main.py status
```

ثم افتح المتصفح على `http://localhost:8080`.

## 🔌 تفعيل موديل حقيقي قوي

المنصة تختار الخلفية تلقائياً (`backend: auto`). لاستخدام موديل حقيقي:

### الخيار 1 — واجهة متوافقة مع OpenAI (موصى به)
يعمل مع OpenAI، vLLM، Ollama، LM Studio، Groq، Together... إلخ.
```bash
export OPENAI_API_KEY="..."                 # مفتاحك
export SENTINEL_MODEL="gpt-4o"              # أو أي موديل
# اختياري: نقطة نهاية محلية/بديلة
export SENTINEL_OPENAI_BASE_URL="http://localhost:11434/v1"   # مثال Ollama
```

### الخيار 2 — موديل محلي عبر Transformers
```bash
pip install torch transformers accelerate
export SENTINEL_HF_MODEL_ID="dphn/Dolphin3.0-R1-Mistral-24B"
```

### الخيار 3 — موديل GGUF محلي (llama.cpp)
```bash
pip install llama-cpp-python
# أعد بناء ملف الموديل من الأجزاء أولاً:
cat Dolphin3.0-Llama3.1-8B-Q4_K_M.gguf.part_* > model.gguf
export SENTINEL_GGUF_PATH="$PWD/model.gguf"
```

> إن لم تُفعّل أي خلفية، تعمل المنصة بخلفية `echo` بلا أعطال (مناسبة للاختبار والعروض).

## 🧩 البنية المعمارية

```
sentinel/
├── core/
│   ├── config.py      # تحميل الإعدادات (env > ملف > افتراضي)، لا أسرار مكتوبة
│   ├── llm.py         # محرك LLM متعدد الخلفيات (openai/transformers/llamacpp/echo)
│   └── agent.py       # وكيل ReAct حقيقي (Thought→Action→Observation→Final)
├── tools/
│   ├── sandbox.py     # حماية من path-traversal، تقييد بمساحة العمل
│   └── registry.py    # أدوات حقيقية: ملفات/كود/shell/بيانات/ويب/أمن
├── security/
│   └── scanner.py     # محرك فحص دفاعي (أسرار/SAST/اعتمادات/إعدادات)
├── api/
│   └── server.py      # REST API + خدمة لوحة التحكم (stdlib http.server)
├── web/templates/
│   └── dashboard.html # واجهة المستخدم
└── platform.py        # الواجهة العليا التي تربط كل شيء
```

## 🛡️ محرك الأمن الدفاعي — ماذا يكتشف؟

| الفئة | أمثلة | الخطورة |
|------|-------|---------|
| تسريب الأسرار | AWS/GitHub/OpenAI keys، مفاتيح خاصة، JWT، سلاسل عالية الإنتروبيا | حرجة |
| أنماط كود خطرة | `eval`/`exec`، `pickle.loads`، `shell=True`، `os.system`، `yaml.load` | عالية |
| التشفير الضعيف | MD5/SHA1، `verify=False` | متوسطة |
| حقن SQL | استعلامات مبنية بدمج السلاسل | عالية |
| الإعدادات | `debug=True`، CORS بـ `*`، الربط بكل الواجهات | متوسطة/منخفضة |
| الاعتمادات | حزم غير مثبّتة الإصدار | منخفضة |

يُخرج تقريراً يحتوي **درجة خطر (0-100)**، عدد النتائج حسب الخطورة، وموقع كل مشكلة مع **توصية إصلاح**.

## 🌐 واجهة الـ API (REST)

| Method | Endpoint | الوصف |
|--------|----------|-------|
| GET | `/` | لوحة التحكم |
| GET | `/api/status` | حالة المنصة والموديل والأدوات |
| GET | `/api/tools` | قائمة الأدوات |
| POST | `/api/chat` | `{"prompt":"...","system":"..."}` |
| POST | `/api/agent` | `{"goal":"..."}` → تتبّع كامل + إجابة |
| POST | `/api/scan` | `{"path":"."}` → تقرير أمني |
| GET | `/health` | فحص الصحة |

مثال:
```bash
curl -X POST http://localhost:8080/api/agent \
  -H 'Content-Type: application/json' \
  -d '{"goal":"افحص الكود في . أمنياً ولخّص أهم 3 مخاطر"}'
```

## 🔒 ضوابط الأمان المدمجة

- **عزل مساحة العمل:** كل أدوات الملفات تمرّ عبر `safe_path` فتمنع `../../` والخروج خارج المجلد.
- **مهلة تنفيذ:** تنفيذ الكود في subprocess بمهلة زمنية قابلة للضبط.
- **قائمة سماح للأوامر:** `run_shell` تقبل أوامر قراءة فقط (ls/cat/grep…).
- **لا أسرار في الكود:** المفاتيح تُقرأ من البيئة فقط ولا تظهر في `/api/status`.
- **تعطيل اختياري:** يمكن إيقاف تنفيذ الكود أو أدوات الشبكة عبر الإعدادات.
