# Dolphin 3.0 R1 Mistral 24B 🐬

هذا المستودع يحتوي على ملفات الإعداد وكود التشغيل لأحدث وأقوى موديل من سلسلة **Dolphin**، وهو موديل **Dolphin 3.0 R1 Mistral 24B**.

## عن الموديل
يعتبر **Dolphin 3.0 R1** الجيل التالي من سلسلة Dolphin الموجهة للتعليمات (Instruct-tuned). تم تصميمه ليكون الموديل المحلي الأمثل للأغراض العامة، بما في ذلك البرمجة، الرياضيات، المهام الوكيلية (Agentic)، واستدعاء الدوال (Function Calling).

تم تدريب نسخة **R1** على 800 ألف أثر تفكير (Reasoning Traces) لتمكينه من التفكير المنطقي العميق قبل الإجابة.

## كيفية الاستخدام

### 1. باستخدام Ollama (الطريقة الأسهل)
يمكنك تشغيل الموديل مباشرة باستخدام Ollama:
```bash
ollama run dolphin3-r1
```

### 2. باستخدام Python (Transformers)
تأكد من تثبيت المكتبات اللازمة:
```bash
pip install -r requirements.txt
```
ثم يمكنك استخدام ملف `inference.py` المرفق لتشغيل الموديل.

## مواصفات الموديل
- **الموديل الأساسي:** Mistral-Small-24B-Base-2501
- **تنسيق الدردشة:** ChatML
- **درجة الحرارة الموصى بها:** 0.05 إلى 0.1
- **الناشر:** [Cognitive Computations (dphn)](https://huggingface.co/dphn)
