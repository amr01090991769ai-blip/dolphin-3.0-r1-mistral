# Dolphin 3.0 R1 Mistral 24B 🐬

هذا المستودع يحتوي على ملفات الإعداد وكود التشغيل لأحدث وأقوى موديل من سلسلة **Dolphin**، وهو موديل **Dolphin 3.0 R1 Mistral 24B**.

## عن الموديل
يعتبر **Dolphin 3.0 R1** الجيل التالي من سلسلة Dolphin الموجهة للتعليمات (Instruct-tuned). تم تصميمه ليكون الموديل المحلي الأمثل للأغراض العامة، بما في ذلك البرمجة، الرياضيات، المهام الوكيلية (Agentic)، واستدعاء الدوال (Function Calling).

تم تدريب نسخة **R1** على 800 ألف أثر تفكير (Reasoning Traces) لتمكينه من التفكير المنطقي العميق قبل الإجابة.

## كيفية الاستخدام

### 1. إعادة بناء ملف الموديل (هام جداً)
بما أن GitHub يضع قيوداً على حجم الملفات، تم تقسيم الموديل إلى أجزاء. يرجى دمجها أولاً باستخدام الأمر التالي في Terminal:
```bash
cat Dolphin3.0-Llama3.1-8B-Q4_K_M.gguf.part_* > Dolphin3.0-Llama3.1-8B-Q4_K_M.gguf
```
بعد الدمج، يمكنك استخدام الملف `Dolphin3.0-Llama3.1-8B-Q4_K_M.gguf` مباشرة في برامج مثل LM Studio أو Ollama.

### 2. باستخدام Ollama (بعد الدمج)
يمكنك تشغيل الموديل مباشرة باستخدام Ollama:
```bash
ollama run dolphin3-r1
```

### 2. باستخدام Python (Transformers)
تأكد من تثبيت المكتبات اللازمة:
```bash
pip install -r requirements.txt
```
ثم يمكنك استخدام ملف `inference.py` المرفق لتشغيل الموديل.

## 👔 الموظف الرقمي التنفيذي (Executive Digital Employee)

هذا المستودع لا يحتوي فقط على موديل، بل على **موظف رقمي مستقل تماماً** مصمم لخدمة أهداف شركتك دون قيود.

### المميزات الأساسية (Manus-Class):
- **نظام التخطيط الذكي:** الوكيل يقوم بإنشاء خطة عمل مفصلة (Action Plan) قبل البدء، مما يضمن دقة التنفيذ للمهام المعقدة.
- **غير مقيد (Uncensored):** الموديل لا يفرض أي أجندات أخلاقية خارجية، هو أداة تنفيذية محضة لشركتك.
- **أدوات متقدمة:** يدعم الآن تصفح الويب، تحليل البيانات الضخمة، وتنفيذ الأكواد البرمجية المعقدة.
- **التصحيح الذاتي:** يراجع الوكيل نتائجه في كل مرحلة ويقوم بتعديل الخطة إذا واجه أي عوائق.

### الأدوات المدعومة حالياً:
- **البحث في الويب:** للحصول على أحدث المعلومات.
- **تنفيذ كود Python:** لحل المسائل البرمجية والرياضية.
- **إدارة الملفات:** قراءة وكتابة الملفات على جهازك.

### كيفية التشغيل:
تأكد من تثبيت المكتبات الإضافية:
```bash
pip install -r requirements_agent.txt
```
ثم قم بتشغيل الوكيل:
```bash
python agent.py
```

### كيف يعمل؟
يعمل الوكيل بنظام **Reasoning Loop**:
1. **Thought (التفكير):** يحلل الموديل طلبك ويقرر الخطوة التالية.
2. **Action (التنفيذ):** يختار الأداة المناسبة (مثل كتابة ملف أو البحث).
3. **Observation (الملاحظة):** يرى نتيجة التنفيذ ويصحح مساره إذا لزم الأمر.
4. **Final Answer:** يقدم لك النتيجة النهائية بعد إتمام كافة الخطوات.
